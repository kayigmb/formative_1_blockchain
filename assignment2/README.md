
```sh
make run
```
## Frequently asked questions:

###  # How to switch between transaction models
##### - When the application start you will have a selection, or when using the system pick choice number 13 and the same prompt will be seen to change the models.


### # How to set mining difficulty level?
##### - With choice number 12 you will be able to set the difficulty level in a range of 1-4.

### # How to test mining simulations:
##### - After you mark the attendance you will have options from 3-5 to simulate the mining using the users in the pening pool.
